修复卫视频道「取址成功、播放列表却一直 403」

【问题现象】
卫视频道全部打不开：拉取节目地址这一步是成功的（接口返回成功、能拿到播放地址），
但紧接着请求播放列表就一律 403，重试几次后提示"源暂时不可用"。
同一次运行里，央视与 4K 频道全部正常。

【原因】
上游会把播放签权绑定到「取节目地址时所用的源网络地址族」上，
后续拉取播放列表必须使用同一族的源地址，否则一律 403。
此前取节目地址走的是 Python 网络栈（优先 IPv6 出口），
而拉取播放列表走的是系统 HTTP 栈（实际走 IPv4），两者地址族不一致，
于是表现为"取址成功、拉取必 403"。

这解释了为什么只在部分网络出现：纯 IPv4 环境下两边天然同族，播放正常；
只有设备同时具备可用的 IPv4 与 IPv6 时才会错配。

【改法】
把整条链路统一到同一地址族：
- 取节目地址改为优先走系统 HTTP 栈，并显式指定地址族（默认 IPv4）；
- 拉取播放列表沿用取址时实际使用的地址族；
- 若取址回退到 Python 栈（其实际选用的族不可控），拉取端交回自动选择，避免再次错配。

【不受影响】
央视与 4K/8K 频道走的是设备协议通道，不经过这条取址链路，行为保持不变。
