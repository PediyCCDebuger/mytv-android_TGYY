【修复】卫视频道列表能拿到、画面却一直不出来
- 卫视频道的分片地址是 https，部分 CDN 边缘节点会把 Python/OpenSSL 的 TLS 指纹
  判成脚本客户端，直接返回 403（错误页文案是 "Invalid Request"，很容易被误认为
  断流或封 IP）。同一条地址改走 http、或改走系统 HTTP 栈都能正常取到，说明与
  账号、签名、出口地址都无关。
- 现在 https 分片收到 401/403/451 时自动改用 http 重试，成功后记住该主机，后续
  分片直接走 http，不再每次都先撞一次无效的 403。

【不受影响】
- 央视与 4K/8K 频道的分片本来就是 http，取址与播放列表链路均未改动。
